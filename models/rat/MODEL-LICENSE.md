# Rat model: third-party asset, not MIT

The MIT License in the repository root covers the **code** only. It does **not**
cover the rat 3D model:

- `models/rat/dist/rat.glb` (mesh, skin weights and textures inside it)
- `models/rat/rat.png` (reference render)

These are derived from a rat model obtained from [CGTrader](https://www.cgtrader.com/)
under CGTrader's royalty-free licence. The rig and animations were generated by
this repository's pipeline, but the mesh and its texture remain the original
author's work and are subject to that licence. The original source files are not
included in this repository.

**Provenance caveat:** the model's vertex-group names (`SKEL_ROOT`, `FACIAL_*`, …)
match the naming used by a commercial game engine, so the asset may originally
come from a commercial game. Its provenance has not been confirmed.

Do not extract or reuse the model from this repository or the published site.
To use this project with your own rat, replace the mesh: the pipeline in
`models/rat/pipeline/` works with any mesh that carries the same vertex-group names.
